Task 1 — Single-Agent Path Planning (A*)

Overview

This task focuses on implementing the A search algorithm* for single-agent path planning in a grid-based environment.

The objective is to find an optimal path between a starting position and a goal position.

Task Description

Implement the a_star function in agent.py using the A* search algorithm.

The algorithm should:

Explore possible paths from the start position to the goal.

Use a heuristic function to guide the search.

Find an optimal path based on the movement costs.

Return a valid path that can be executed in the provided environment.

Implementation

The implementation consists of two Python files:

agent.py — Contains the A* search algorithm.

environment.py — Provides the grid environment, path execution, and visualisation functionality.

Testing

The implementation can be tested using the provided environment and three test cases.

The expected outcome is a valid, optimal path from the starting position to the goal position.

Learning Outcomes

Understanding heuristic search algorithms.

Implementing A* for path planning.

Applying pathfinding algorithms to grid-based environments.

Evaluating solution correctness and optimality.
