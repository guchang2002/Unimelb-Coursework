Victoria rainfall grid.asc

This file is an ESRI ASCII Grid file that shows average annual rainfall values across Victoria. The
data is averaged over the standard 30-year period 1961 to 1990.

Coordinate system: Geographic coordinates, GDA 1994

Data source: Bureau of Meteorology Climate Data Online, http://www.bom.gov.au/jsp/ncc/climate_averages/rainfall/index.jsp

Detailed metadata is available at http://www.bom.gov.au/climate/map/rainfall/average-rainfall-metadata.pdf
